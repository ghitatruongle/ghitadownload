# 0.0.5-beta Implementation Plan

> **For agentic workers:** Steps use checkbox (`- [ ]`) syntax for tracking. Implement against `docs/superpowers/specs/2026-10-28-0.0.5-beta.md`.

**Goal:** Ship `0.0.5-beta` with LRCLIB lyrics embedding, `--resume` batch continuation, yt-dlp 2026.10.26 bump, and crossterm/dirs upgrades — no breaking CLI/config changes.

**Architecture:** Keep the two-binary crate, `BatchProcessor` pipeline, and yt-dlp/FFmpeg wrappers. Add `core/lyrics.rs` beside `tagger.rs`; reuse `utils/http::with_retry` for LRCLIB calls and `utils/fs::replace_file` for atomic `pending_tasks.json` writes. `FailedQueue` is reused as the pending-state shape.

**Tech Stack:** Rust 2021, Clap 4, Tokio, reqwest, id3, FFmpeg, LRCLIB HTTP API.

## Global Constraints

- Package version exactly `0.0.5-beta`; artifact `Release/ghitadownload_0.0.5-beta.exe`.
- Existing CLI flags, format/quality values, exit codes, `AppConfig`/`FailedQueue` JSON remain compatible (`serde(default)` on every new field).
- No comments (`//`, `///`, `/* */`) in `src/`, `tests/`, `build.rs`; README headings keep no icons.
- `cargo fmt --check`, `cargo clippy --locked --all-targets -- -D warnings`, `cargo test --locked` must pass at the end of each task batch.
