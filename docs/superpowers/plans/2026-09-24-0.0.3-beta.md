# 0.0.3-beta Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Release a Windows installer named `ghitadownload_0.0.3-beta.exe` with consistent version metadata and reliable bootstrap/installer failure behavior.

**Architecture:** Keep the existing Rust library, two binaries, and manual Windows installer flow. Move release validation into the build script plus a small PowerShell verifier, make the setup binary return `Result`-style failures through `main`, and route headless yt-dlp updates before full environment preparation. Add isolated tests for the new release contracts and keep the existing FFmpeg/network tests as environment-dependent integration tests.

**Tech Stack:** Rust 2021, Cargo, Clap 4, Tokio, PowerShell, Windows batch files, `yt-dlp`, FFmpeg.

**Spec:** `docs/superpowers/specs/2026-09-24-0.0.3-beta.md`

## Global Constraints

- The package version is exactly `0.0.3-beta`.
- The active installer artifact is exactly `Release/ghitadownload_0.0.3-beta.exe`.
- Build the main `ghitadownload` binary before `ghitadownload-setup`.
- A release build must fail when either the main executable or `bin/yt-dlp.exe` is unavailable or invalid.
- Existing CLI flags, format/quality values, and exit-code meanings remain compatible.
- Existing `AppConfig` JSON remains readable without migration.
- Do not add new external providers, formats, quality tiers, CI workflows, signing configuration, or dependency pins in this beta.
- Do not commit `target/`, `bin/yt-dlp.exe`, runtime `ghita_config.json`, or downloaded media.

- [ ] **Step 1: Create the PowerShell verifier**

Implement `scripts/verify_release.ps1` with these checks:

```powershell
$ErrorActionPreference = "Stop"
$versionLine = Select-String -Path "Cargo.toml" -Pattern '^version = "(.+)"$' | Select-Object -First 1
$version = $versionLine.Matches[0].Groups[1].Value
if ($version -ne "0.0.3-beta") { throw "Unexpected version: $version" }

$artifact = Join-Path "Release" "ghitadownload_$version.exe"
if (!(Test-Path $artifact)) { throw "Missing release artifact: $artifact" }

$bytes = [IO.File]::ReadAllBytes($artifact)
if ($bytes.Length -lt 1024 -or $bytes[0] -ne 0x4D -or $bytes[1] -ne 0x5A) {
    throw "Artifact is not a valid Windows PE executable"
}

$hash = (Get-FileHash -Algorithm SHA256 $artifact).Hash
Write-Host "Release artifact: $artifact"
Write-Host "SHA-256: $hash"
```

The script must not print the full binary or secrets; it prints only the path, version, size, and digest.
