# 0.0.5-beta Specification

**Phiên bản đích:** `0.0.5-beta` — bản ổn định hóa `0.0.5-alpha` kèm hai tính năng mới (lyrics, resume) và bump công cụ.

**Phạm vi:**

1. **Nhúng lời bài hát (LRCLIB)** — module `core/lyrics` tra LRCLIB (`/api/get`, fallback `/api/search`) theo artist + title + duration; chọn ứng viên gần thời lượng nhất, ưu tiên có lời đồng bộ. Nhúng lời thường: MP3 qua frame ID3 USLT; FLAC/M4A/Opus qua mux pass FFmpeg `-c copy -metadata lyrics=`. Ghi `.lrc` đồng bộ cạnh tệp nhạc. Thất bại lấy lời không làm hỏng task. WAV/Original/Video bỏ qua. Mặc định bật; tắt bằng `--no-lyrics` hoặc menu cài đặt dashboard (lưu vào `AppConfig.fetch_lyrics`).
2. **Resume batch** — mỗi batch ghi `pending_tasks.json` vào thư mục xuất lúc bắt đầu, cập nhật sau mỗi task thành công, xóa khi batch kết thúc. Nếu tiến trình bị giết giữa chừng, `--resume --output <DIR>` tải lại đúng các task còn lại. Cờ chạy riêng như `--retry-failed`.
3. **Bump yt-dlp** `2026.08.19` → `2026.10.26` đồng bộ 4 vị trí pin; SHA-256 lấy từ `SHA2-256SUMS` chính thức.
4. **Bump dependency** crossterm 0.25→0.28 (kèm filter `KeyEventKind::Press`), dirs 5→6. Giữ nguyên pin FFmpeg.

**Ngoài phạm vi:** tách `suno.rs`, dedupe bài đã tải, AI re-rank matching, playlist M3U.

**Tương thích:** cờ CLI, định dạng/chất lượng, mã thoát, JSON `AppConfig`/`FailedQueue` giữ nguyên; các trường mới (`fetch_lyrics`, `lyrics`) đều `serde(default)`. `pending_tasks.json` là tệp mới, tự xóa khi batch hoàn tất.

**Chấp nhận:** `cargo fmt --check`, `cargo clippy --locked --all-targets -- -D warnings`, `cargo test --locked`, pin check đồng bộ, build installer thành công, `verify_release.ps1` pass, smoke test sống tải được bài thật bằng yt-dlp 2026.10.26.
