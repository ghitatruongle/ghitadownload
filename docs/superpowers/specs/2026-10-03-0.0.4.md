# 0.0.4 Release Specification

## Goal

Ship `0.0.4`: fix high-priority stability bugs, add cookies/metadata/Opus/manifest features, refactor duplicated filesystem and regex hot paths, and harden CI without breaking the existing CLI/config contract.

## Scope

Included:

- Suno playlist pagination (`fetch_playlist` follows every page until empty).
- Cancellation: Ctrl+C terminates child yt-dlp/FFmpeg processes and marks the failed queue.
- Replace nested `current_thread` runtime inside `spawn_blocking` Suno decrypt with an async-native path.
- `JoinSet` error mapping records the correct `task_index`.
- Always backoff between yt-dlp retries; retry helper with backoff for Spotify/Suno HTTP 429/timeout.
- Sweep stale `.ghita_temp_*` directories on batch start.
- Remove hard-coded per-machine Python path in `env.rs`.
- `--cookies <file>` and `--cookies-from-browser <browser>` flags forwarded to yt-dlp.
- Embed cover/metadata for FLAC and M4A (AAC) outputs in addition to MP3.
- `--format opus` output (Opus in Ogg/WebM container) with matching quality map.
- Write a JSON manifest (`ghita_manifest_<timestamp>.json`) of succeeded/failed tasks after each batch.
- Refactor: shared `utils/fs::replace_file`, `build_task` helper in resolve.rs, `LazyLock` regexes, shared HTTP client in spotify/suno/tagger, yt-dlp constant args in `core/ytdlp.rs`.
- CI: `cargo audit`, yt-dlp download cache, installer smoke (`--version`, `--help`), CHANGELOG/tag cross-check, dependabot config.
- Bump version to `0.0.4`, update CHANGELOG, README install/version references.

Out of scope:

- New platforms beyond existing Instagram/etc parsers (no new extractors logic other than cookies passthrough).
- TUI rewrite with ratatui; only cancellation wiring is added.
- Code signing, MSIX, winget packaging.
- Pinning new FFmpeg/yt-dlp versions.

## Release constraints

- Package version exactly `0.0.4`; artifact `Release/ghitadownload_0.0.4.exe`.
- Existing CLI flags, format/quality names, exit codes, and `AppConfig`/`FailedQueue` JSON remain compatible.
- `--format opus` must not change defaults of existing formats; `original`/`video` semantics unchanged.
- `--cookies-from-browser` values restricted to yt-dlp supported list; invalid value exits non-zero.
- Cancellation must still write `failed_tasks.json` for the in-flight task.
- No comments (`//`, `///`, `/* */`) added to `src/`, `tests/`, `build.rs`.

## Acceptance criteria

1. `cargo test --locked`, `cargo fmt --check`, `cargo clippy -- -D warnings` pass.
2. `ghitadownload --version` reports `0.0.4`.
3. Suno playlist id returns all clips across pages in unit test with mocked pages (no network).
4. Headless run with `--link ... --format opus --quality 192k` produces an `.opus`/`.ogg`/`.webm` file or exits non-zero with clear message; refuses incompatible quality.
5. `--cookies missing.txt` exits non-zero before download.
6. Manifest JSON exists after a batch and lists per-link status.
7. Repeated runs do not accumulate stale `.ghita_temp_*` dirs.
8. CI runs audit + cached yt-dlp + installer smoke; dependabot file present.
9. CHANGELOG contains `## [0.0.4]` and release notes name the artifact and SHA-256.
